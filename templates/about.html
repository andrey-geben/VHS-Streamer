Миграция на другой ARM по SSH

В ARM-комплект входит migrate_to_arm.sh. Скрипт переносит установку VHS-Streamer на другой ARM-сервер по SSH: копирует комплект, запускает установщик, переносит конфигурацию и данные, затем запускает службу на новом устройстве.

  1. SSH-ключ и вход на новый ARM без пароля.
  2. sudo без пароля на новом ARM.
  3. Запуск миграции с флешки или со старого сервера.
  4. Скрипт копирует комплект и выполняет install_jetson.sh.
  5. Переносятся config.yaml, archive/ и events.db.
  6. Служба на новом ARM запускается и проверяется.
./migrate_to_arm.sh user@new-arm \
    --data-from /opt/vhs-streamer \
    --stop-source

Для локальной сети добавьте --open-ports. Для edge-схемы порты открывать не нужно: доступ идёт через WireGuard.

Важно: перед копированием архива остановите старый экземпляр, иначе файл может быть скопирован в момент записи.
